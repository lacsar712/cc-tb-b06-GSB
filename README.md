# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

## 汤色留影

- 仅结论为「通过」的审评可挂汤色留影，不通过行服务端直接 403 拒绝。
- 上传不落大图文件：服务端按说明句算出摘要短串（`汤影-` + SHA-256 前 10 位）存库。
- 修改说明句不会改动已存短串；要换短串必须重新走上传。重新上传只保留新短串，并写一条覆盖备忘（旧短串、新短串、操作者、时刻）。短串未变的重传不产生备忘。
- 顶栏「汤色留影」进专页，可按审评编号翻看当前有效留影与覆盖备忘列表；列表行也展示当前短串。
- 审评员（taster）可上传；观察员（observer）能看留影与备忘，不能上传。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 给春茶-A 挂汤色留影后，审评列表该行出现摘要短串。
5. 对春茶-A 再挂一次，当前只保留新短串，覆盖备忘中可见旧短串、新短串、操作者、时刻。
6. 对夏茶-C 挂留影被拒（403）；observer 上传也被拒，但可在专页查看留影与备忘。
