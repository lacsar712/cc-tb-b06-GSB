# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

汤色留影：通过行可挂“汤色留影”。上传时服务端依据说明句算出摘要短串落库，不存大图文件。短串一经上传即冻结，事后改正说明句不回改短串；要换短串必须重新走上传，系统会把旧短串、新短串、操作者、时刻写入覆盖备忘。不通过行禁止挂留影。顶栏进入“汤色留影”专页，可按审评编号翻当前有效留影与覆盖备忘。审评员可上传，观察员只可查看。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进入汤色留影专页，给春茶-A 挂留影（填说明句）后，列表出现摘要短串。
5. 改正审评说明句，已存短串不变。
6. 对春茶-A 再挂一次：当前有效留影只保留新短串，覆盖备忘中可见旧短串、新短串、操作者、时刻。
7. 对夏茶-C（不通过）挂留影被拒（403），不落库。
8. observer 能在专页看留影与备忘，但页面无上传表单，直接 POST 被 403。
